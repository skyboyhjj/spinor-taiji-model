# 《唯识对读》术语表

> 按读这一集的需要编排，不按词典顺序。
> 依据以《成唯识论》（玄奘译）为主，兼采《摄大乘论释》《因明入正理论》。

---

## 一、基本框架

**三能变**　识有三种转起方式：第八阿赖耶识（异熟能变）、第七末那识（思量能变）、前六识（了别境能变）。「此能变为三，谓异熟思量，及了别境识。」（《唯识三十颂》）

**阿赖耶识**　第八识，含藏一切种子。三名：阿赖耶（自相，能藏／所藏／执藏）、异熟识（果相）、一切种识（因相）。

**末那识**　第七识，恒审思量，执第八识见分为「我」。有覆无记。

**前六识**　眼耳鼻舌身意。前五识唯现量取境，无深分别；第六识造业力最强。

**无覆无记**　阿赖耶识的三性归属：不善不恶，不覆障圣道。**正因为它不挑，才容得下善，也容得下恶。**「任运而转」描述的是运作方式，不是价值性质。

**四根本烦恼**　末那识恒俱的四支：我痴、我见、我慢、我爱。是「任运而起却属染污」的标准例证。

**四分**　相分（所缘影像）、见分（能缘作用）、自证分、证自证分。凡识皆具。

## 二、种子

**种子**　阿赖耶识中「亲生自果功能差别」。**不是实体，是功能；但也不是假法**——「虽非一异而是实有，假法如无，非因缘故」（《成唯识论》卷二）。属依他起性。

**现行**　种子遇缘所生起的具体活动。种子是潜能，现行是它当下的实现；而现行又会反熏成新种——这就是「种子生现行、现行熏种子」的循环。

　　《成唯识论》卷十作「**现起**」（「彼障现起，地前已伏」），与「现行」同指。第一篇、第三篇引文用「现起」，是随原文。

**种子六义**　成立种子的六项条件，出自《成唯识论》卷二：

| 义 | 原文要旨 | 一句话 |
| :-- | :-- | :-- |
| 刹那灭 | 体才生，无间必灭 | 才生即灭，不是常住 |
| **果俱有** | 与所生现行果法，俱现和合 | **因果同时在，不是先后** |
| 恒随转 | 长时一类相续，至究竟位 | 自类相生，续得长 |
| 性决定 | 随因力，生善恶等功能决定 | 善种生善果，性质不混 |
| 待众缘 | 要待自众缘合，功能殊胜 | 须条件具足才起 |
| 引自果 | 于别别色心等果，各各引生 | 色种生色，心种生心 |

**性决定**　种子六义之三。善种子只生善果，恶种子只生恶果，性质不杂乱。**它是「功能有确定性」，不是「谁规定了善恶」**——《成唯识论》作「随因力，生善恶等功能决定」。此义最常被读成道德训诫，其实是功能描述：火必然热，善种必然生善果。

**引自果**　种子六义之六。色法种子只引生色法现行，心法种子只引生心法现行，各引自类之果，不互代。与「性决定」成对：**性决定管「性质不混」，引自果管「类别不乱」。**



**本有种子／新熏种子**　种子二类：无始来法尔而有者（本性住种），及由现行熏成者（习所成种）。

**有漏种子／无漏种子**　有漏者系属生死流转，无漏者指向解脱。有漏种与异熟识体无别，故属无记；无漏种因果俱善。

**本有无漏种子**　法尔本有的无漏种子。它「不必待新熏，然仍待外缘而得生起」——不待新熏，不等于无条件自起。

## 三、熏习的条件

**熏习**　现行反熏本识、留下新种的过程。「能熏与所熏识，俱生俱灭，熏习义成，令所熏中种子生长，如熏苣蕂，故名熏习。」（《成唯识论》卷二）

**数数熏习**　「数数」是屡次、一次又一次。熏习非一次即成，须反复熏，种子才增长。儒家「学而时习之」的「时」训作「时时」，与「数数」同拍——第二篇就是从这里起读的。

**所熏四义**　什么法够格当「被熏的处所」——唯第八识具足：

- **坚住性**：始终一类相续，能持习气。
- **无记性**：平等无所违逆，能容习气。善恶势力强盛者装不进新东西。
- **可熏性**：性非坚密，能受习气。
- **与能熏共和合性**：同时同处，不即不离。



**能熏四义**　什么法够格当「能熏者」——唯前七转识及心所：

- **有生灭**：非常，能有作用。
- **有胜用**：势力增盛，能引习气。
- **有增减**：可增可减，摄植习气。**此遮佛果圆满善法，无增无减，故非能熏。**
- **与所熏和合而转**：同时同处。



**正闻熏习**　唯识自己造的、自带方向的词。「无倒听闻如是经等故名正闻……**或复正闻即是熏习**，是故说名正闻熏习。」（世亲《摄大乘论释》卷三）

**串习（vāsanā）**　由反复的身口意行为留下的习惯性势力，比一般种子更具惯性与自发性。种子说「能做什么」，现行说「在做什么」，**串习说「总是倾向做什么」**。

## 四、伏与断

**伏**　令烦恼**现行**不起。「由前道力折伏……令其不行，名之为伏。」（《成唯识论述记》）伏不是消灭——**如咒药所伏诸毒，毒还在，发作不了。**

**断**　令烦恼**种子**不复生。与「伏」是两个层面。

**地前**　十地之前，即资粮位与加行位——已发心修行、尚未见道的人。**现行在此可伏，种子在此不断。**

**见道**　初见真如，即通达位、初地。分别二障的种子于此初断。

**不退转（avaivartika）**　修行至初地以上，不退堕恶趣、不退失善根。**这是阶位概念**。与第四篇标题里的「不退」（不退失对它的觉察）字面相同，所指不同。

**金刚喻定**　等觉位最后之定，俱生二障种子于此一切顿断。

**二障**　烦恼障（我执为主）与所知障（法执为主）。

## 五、转依

**转依**　转舍杂染、转得清净。「但转其名，不转其体」——转的是名与用，不是那个体。

**转识成智**　有漏八识转为无漏四智：

| 识 | 智 |
| :-- | :-- |
| 第八识 | 大圆镜智 |
| 第七识 | 平等性智 |
| 第六识 | 妙观察智 |
| 前五识 | 成所作智 |



**根本智／后得智**　见道时所生：根本智契真如（无分别），后得智于其后起，能如实照见诸法差别。**四智是佛果所成，不可与初地二智混说。**

## 六、三性与认识

**三性**　遍计所执（妄执实有，体相都无）、依他起（众缘所生，实有而无自性）、圆成实（于依他起上离遍计所执所显之真如）。

**假法／实法**　唯识的严格分判。假法如龟毛兔角，毕竟无，不能作因缘；实法指依他起的有体之法。**种子是实法，不是假法。**

**现量／比量**　现量「谓无分别……离名种等所有分别」（《因明入正理论》），不许任何概念成分；比量是推论。

**非量**　既非现量亦非比量的错乱认知（如误认绳为蛇）。三量——现量、比量、非量——是《因明入正理论》的认识论框架。第三篇用它判「生知」：不是现量、不是严格比量、也不是非量，**三量皆不相应，恰恰说明它不是一个认识论范畴。**

---

## 七、识与境

**识境不二**　识与境相互依待、共同缘起：没有离开境的识，也没有离开识的境。**此为本系列的用语，非古典名相**——唯识原典多说「唯识无境」「识所变」，不说「不二」。第五篇借它统摄两篇 AI 论文：一者转「识」，一者转「境」。

**共业**　众生共同造作、共同承受的业力，感得共同的环境。「共业串习」指互联网文本承载的集体思维惯性——不是某一个 Agent 在创造环境，是整个 Agent 群体的互动历史在塑造未来个体所要面对的训练场。

## 八、缘起与法尔

**缘起**　「此有故彼有，此生故彼生；此无故彼无，此灭故彼灭。」诸法依因缘而生灭，无有自性。《杂阿含》299 经：「缘起法者，非我所作，亦非余人作，然彼如来出世及未出世，法界常住。」——**缘起不是佛制定的，佛只是发现它。**

**法尔（法尔如是）**　「法」指诸法，「尔」即如此：法就是这样。**它不是「不许再问」，恰恰是问到底之后的答案**——把因缘、条件、性质一层层追下去，追到最后，只能答「它本来如此」。《瑜伽师地论》卷二十五列「四种道理」，法尔是第四；卷七十八定义为「如来出世，若不出世，法性安住，法住法界」。

　　此词最危险的读法，是把「本来如此」听成「有一个永恒实体躲在万法背后」。**忘了缘起，它就成了本体论；记得缘起，它清澈见底。**

**法性、真如、性空**　三名一系。「法性」是诸法本然之性，「真如」是如实不虚，「性空」是找不到独立自成的自性。三者都指向「诸法本来如此」，但**都不可再被实体化**——《大智度论》卷九十说得干脆：「从本已来常空，无有作者……但性自尔故。」在「空」后面再立一个「空的本体」，正是它要破的。

**四种道理**　《瑜伽师地论》卷二十五的判准分类：观待道理（因果相依）、作用道理（各有功能）、证成道理（三量证成）、法尔道理（本来如此）。**「法尔」在这一组里是最后一格**——前三格还能继续追问，问到第四格，只能答「法性应尔」。

**四缘**　种子生现行须四缘具足：

| 缘 | 是什么 | 能不能动 |
| :-- | :-- | :-- |
| 因缘 | 种子本身 | 动不了 |
| 等无间缘 | 前念灭、后念生的相续链 | 难动，但可插入断点 |
| 所缘缘 | 所对的对象 | **能动：让对象不出现** |
| 增上缘 | 其余一切辅助条件 | **能动：换环境** |

**逆增上缘**　本是违逆、障碍之缘，却反向助成道业。**障碍并未变成助缘本身，是修行人把它转成了助缘**。第四篇讲「改过」即用此理：犯过的记忆不必消除，可转为不再犯的条件。

## 九、易混辨析（读这一集最需要）

| 容易混的 | 分别在哪 |
| :-- | :-- |
| 「识」读 zhì ／「识」vijñāna | 前者是「记住」（「多学而识之」），后者是「了别」。同字，不同义 |
| 「生知」／「现量」 | 现量不许概念成分；生知所知是道理礼义，必含名分别。**定义上冲突** |
| 「伏」／「断」 | 伏动现行，断动种子。地前只能伏，见道以上才谈断 |
| 依他起「实有」／「假法」 | 种子是实有（缘起有），不是假法；但也不是遍计所执的实我实法 |
| 「无记性」（所熏）／「性决定」（种子） | 前者是**受体**不挑，后者是**种子**性质不混。一个说能容，一个说生果 |
| 「串习」／「种子」 | 种子是潜能单元，串习是反复累积出的**倾向势力** |
| **「法尔」／「宿命」** | 法尔说「因缘如此，故其如此」，**条件变了结果就变**；宿命说「无论如何，结果已定」。形状相似，方向相反 |

## 附：不在唯识系统内的词

读后几篇会碰到，特此说明——它们是现代概念，只作对读，不是唯识名相：

- **块对角**：线性代数概念（矩阵分块、块间不耦合）。文中借以说明「引自果」与「性决定」在权重空间的两种强弱程度。
- **EnvHarness／EnvRigger**：谷歌团队的环境框架，动 Stage（起点）、Contract（规则）、Chain（任务长度）。
- **agent／agency／action**：寿步教授用以对读「本识／种子／现行」的三个 AI 概念。
